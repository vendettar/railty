## 4. Reproduction recipe (run on an Xcode-capable Mac)

```bash
# 1. Build benchmarks (needs full Xcode for metallib)
zig build -Demit-bench -Doptimize=ReleaseFast -Demit-macos-app=false

# 2. Deterministic corpora
zig-out/bin/ghostty-gen ascii > /tmp/ascii.vt
zig-out/bin/ghostty-gen styled-heavy > /tmp/styled-heavy.vt

# 3. Terminal throughput (warmup + repeated runs; record median and spread)
hyperfine --warmup 3 --runs 10 \
  'zig-out/bin/ghostty-bench +terminal-stream --data=/tmp/ascii.vt --scrollback=50MB'

# 4. Resize / reflow
hyperfine --warmup 3 --runs 10 \
  'zig-out/bin/ghostty-bench +terminal-resize --data=/tmp/ascii.vt'

# 5. Snapshot codecs
hyperfine --warmup 3 --runs 20 \
  'zig-out/bin/ghostty-bench +terminal-snapshot --mode=encode --loops=20 --data=/tmp/ascii.vt' \
  'zig-out/bin/ghostty-bench +terminal-snapshot --mode=decode --loops=20 --data=/tmp/ascii.vt'
```

Measurement rules:

- Same machine, same power state, same build mode (`ReleaseFast`), same corpus and dimensions.
- Warm up before timing; run at least 5 repetitions; report median and min/max.
- Never treat GitHub Actions build-duration changes as terminal throughput improvements.
